# SKG
SKG or *Stacked Keyboard Generator* is a CAD and CAM software that I developed for my CO2 laser machine. Drawing a mechanical keyboard made of acrylic sheets is time consuming, especially when the design is almost the same for keyboard to keyboard. So I developed an application to generated the production files automatically. As a "side-project" or in the conjunction, I developed a [3D viewer](https://ek-viewer.pages.dev/?type=stacked&keyboardId=34&tc=ffa500&tt=transparent&bc=ffa500&bt=transparent&swc=32cd32&sdc=32cd32) that can be embedded on a website.
