An acrylic bending machine is a great tool to add in your workshop if you work with a CO² laser cutting machine and want to produce more premium parts. The machine uses an heating element, generally made out of an NiChrome wire. Will applying DC current to the wire, the wire heat up and soften the plastic above it.

## BOM

### Wooden parts

| Part name      | Dimensions | Quantity |
| -------------- | ---------- | -------- |
| Base           | 900 x 600  | 1        |
| Top            | 700 x 400  | 1        |
| Rotating panel | 700 x 200  | 1        |

### Aluminium extrusions

| Part name | Dimensions | Quantity | Comment                      |
| --------- | ---------- | -------- | ---------------------------- |
| U profile | 700        | 1        | Miminal size: 12 x 12 mm     |
| L profile | 600        | 2        | Recommended size: 50 x 20 mm |
| L profile | 300        | 2        | Recommended size: 50 x 20 mm |
| T track   | 200        | 2        | _Optional_                   |

### Miscellaneous

| Part name             | Quantity | Comment                                                  |
| --------------------- | -------- | -------------------------------------------------------- |
| NiChrome wire         | 1000 mm  | Try to find grade A wire: 80% nickel, 20% chromium       |
| M6 x 12 wood insert   | 6        |                                                          |
| M6 x 18 bolt          | 6        |                                                          |
| 3 x 16 wooden screw   | 22       |                                                          |
| 3,5 x 30 wooden screw | 6        |                                                          |
| Hinge                 | 2        |                                                          |
| T track slot          | 2        | _Optional if you don't add T track on the rotating part_ |
| Angle stops           | 2        | _Optional_                                               |

## Steps

1. Pre-drill all the holes on every panels, if you choose to add the `T tracks`, take the time to use a router and mill the 2 grooves on the `Rotating panel`,
1. Insert the `M6 x 12 wood inserts` on the `Base` and `Top` panels,
1. Screw the `Top` part on the `Base`,
1. Screw the `U profile` on the `Base`. If the `U profile` is thinner than the `Top` panel thickness, add washers between the `Base` and the `U profile`,
1. _Optional_, screw the 2 `T tracks` on the `Rotating panel`
1. Present the `Rotating panel` next to the `U profile`, then screw the 2 `Hinges` on both side as well as on both sides on the `Top` panel,
