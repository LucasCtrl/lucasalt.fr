Working in a workshop equipped with CNC machines is a dream come true for me. But that dream fades when you have to identify the tools stored on the tool carts. A common solution is to write the tool number on a piece of painter's tape and stick it to the tool holder.

The problem is that if you leave the tape on for too long, the adhesive sticks to the holder when you remove it. This problem is greatly increased because most workshops are neither air-conditioned in the summer nor heated in the winter, which alters the properties of the adhesive.

To solve this problem, I designed a small card that clips into the groove of the tool holder.

This card is made of acrylic (PMMA) to avoid issues with cleaning products and oils found in workshops. Furthermore, it's very practical because you can write the tool number on it with a dry-erase marker, allowing you to clean it and reuse it.
